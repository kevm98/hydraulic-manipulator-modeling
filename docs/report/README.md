# Report source

The revised manuscript uses unmodified IEEEtran conference mode with US letter paper, default two-column layout, numbered equations, and IEEEtran bibliography style. It retains Kevin Kudakwashe Murera's authorship and institutional affiliation without student identifiers.

## Build

From this folder with a standard TeX installation:

```bash
pdflatex -interaction=nonstopmode -halt-on-error main.tex
bibtex main
pdflatex -interaction=nonstopmode -halt-on-error main.tex
pdflatex -interaction=nonstopmode -halt-on-error main.tex
cp main.pdf hydraulic_manipulator_report_ieee.pdf
```

The class and bibliography style are included with upstream notices. `construction.tex` contains the actuator assembly and network chapters. Result plots are generated by `scripts/build_figures.py`, and the construction schematics by `scripts/build_construction_figures.py`. Numerical and image sources are documented in `docs/DATA_AND_FIGURES.md`.

## Construction details

The report includes the annotated mechanical topology, the complete original actuator and integrated-model views, a chamber/assembly diagram, a saved-network reconstruction, and expanded valve-routing diagrams. Tables distinguish active cylinder settings, disabled alternatives, supply/fluid parameters, and controller gains.

Selected settings and connection groups can be inspected in [the model specification](../model-specification.json). Rebuild it without MATLAB using:

```bash
python3 scripts/extract_model_specification.py
```

Run that command from the repository root. It reads the saved model; it does not compile or validate its physical behavior.

## Sources and formatting

The main source is the earlier written report, supplemented by the GitLab presentation, editable model, embedded controller, analysis scripts, and numeric FIG contents. Original versions are retained. No new simulations or hardware tests are claimed.

Primary references were checked against [Wiley's Merritt record](https://www.wiley-vch.de/en/areas-interest/engineering/mechanical-engineering-10me/fluid-mechanics-10me3/hydraulic-control-systems-978-0-471-59617-2), [Springer's Jelali/Kroll record](https://link.springer.com/book/10.1007/978-1-4471-0099-7), and official MathWorks documentation for [model import](https://www.mathworks.com/help/sm/ref/smimport.html), [actuator equations](https://www.mathworks.com/help/hydro/ref/doubleactingactuatoril.html), and [stiff integration](https://www.mathworks.com/help/matlab/ref/ode15s.html).

The layout follows [IEEE conference author guidance](https://events.ieee.org/planning-basics/ieee-conference-publications/publishing-information-for-ieee-conference-authors/).
